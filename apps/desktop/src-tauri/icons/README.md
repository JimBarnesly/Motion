# Motion application icon

The original Motion mark uses interlocking rounded page planes to suggest linked knowledge and forward movement. Its charcoal, muted teal, and warm off-white palette is intentionally calm and legible at small sizes. It does not reuse another product's logo, typography, or assets.

`icon.png` is the 512 px RGBA master normalized by the Tauri 2 icon tool. The 32 px, 128 px, and 256 px PNGs are the required Linux/Tauri derivatives generated from that master.
