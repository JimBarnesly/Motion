# User Stories

## Local workspace

- As an offline user, I can create and reopen a workspace without signing in.
- I can create, rename, reorder, nest, archive, and restore pages without breaking links.
- I can edit typed blocks, use undo/redo, and operate every drag action from the keyboard.
- I can enter `[[Page name]]` or a page mention and see stable links and backlinks.
- I can search titles, content, properties, filenames, and links with keyboard navigation.
- I can add an attachment and reopen the exact local file after restart.

## Collections

- I can define typed properties and records-as-pages.
- I can save table/list/board/calendar/gallery/timeline configurations over the same records.
- I can apply nested typed filters and stable multi-column sorts without raw SQL.
- I can relate records and compute rollups without recursive cycles.
- I can use deterministic versioned formulas and see explicit errors.

## Ownership and recovery

- I can export a page to Markdown, a collection to CSV, and a full workspace losslessly.
- I can preview and verify a backup, then restore it into a new workspace.
- I can inspect all network-dependent settings and keep them disabled.

## Later collaboration and automation

- I can self-host sync, reconcile offline edits, and inspect unsafe conflicts.
- As an administrator, I can assign explicit roles and audit permission decisions.
- I can select the exact content sent to an AI provider and approve any proposed mutation.
- I can grant an MCP client separate, revocable read and write scopes.

These are target stories; `STATUS.md` distinguishes implemented from planned behaviour.
